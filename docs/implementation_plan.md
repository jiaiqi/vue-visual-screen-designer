# 工业组态与大屏可视化编辑器 - 全新架构设计方案

基于您提供的参考截图（对标“乐吾乐”这种包含 2D/3D 和动态元件的专业工业组态软件）以及对高级图元（动态流体管道、旋转风扇、立体图形）的严苛要求，我们之前的 Fabric.js 方案在复杂场景下显得力不从心（特别是节点连线、事件路由、HTML UI 嵌入）。

因此，针对该需求，我们进行了一次彻底的技术重估与方案重塑。

## 0. 底层技术选型与深度对比

对于实现**“现代工业组态编辑器”**，以下是各大主流前端图形库的对比：

| 特性 / 库 | Fabric.js (原方案) | Vue Flow | Konva.js | **AntV X6 (最佳推荐!)** |
| :--- | :--- | :--- | :--- | :--- |
| **核心定位** | 自由 2D 画布 (类 PS) | 逻辑节点连线图 (类 Node-RED) | 高性能 2D 骨架 | **专业图编辑系统，复杂连线与组态** |
| **渲染机制** | Canvas 纯绘图 | HTML/DOM | Canvas | **SVG + HTML/Vue 组件无缝嵌套** |
| **基础图元支持** | 良好 | 较弱 (需手写 Node) | 良好 | **极佳 (内置几十种图元，高度定制)** |
| **管道连线与流体**| **极难** (需大量手写数学运算) | 一般 (支持连线，但自由度低) | 较难 | **开箱即用，强大的边(Edge)动画体系** |
| **动画效果(风扇)**| **极难** (需 Canvas 每帧重绘) | 容易 (DOM 组件 CSS) | 较难 | **极易 (支持挂载 Vue 组件，可使用 CSS 动画)** |
| **立体图形(2.5D)**| 较难 (靠贴图和复杂绘制) | 不适合 | 一般 | **支持任意 SVG 滤镜和 DOM 立体透视组合** |
| **锚点/对齐吸附** | 需手写 | 自带 | 需手写 | **内置专业体系，极度完善** |

**最终决断：全面拥抱 `@antv/x6` 及其 Vue 生态 `@antv/x6-vue-shape`。**
X6 是目前前端做**工业组态、拓扑图、SCADA 系统**事实上的标准。它能把 Vue 组件直接渲染成画布里的实体，这意味着我们可以用常规的 Vue/CSS 写出旋转的 3D 风扇，然后直接丢进 X6 画布中受其管理。

## 1. 系统宏观架构 (System Architecture)

页面将采用**深色工业风主题 (Dark Theme)** 重新组织：

- **顶栏 (HeaderBar)**: 包含核心操作（保存、导出、3D/2D 切换、播放/停止动画）。
- **左侧素材库 (Stencil / Sidebar)**: 
  - **基础图元**: 直线、曲线、圆、三角形、梯形、矩形、文本（X6 内置丰富形态）。
  - **高级图元**: 动态管道（水平/垂直弯头）、单/双向动画箭头。
  - **工业设备**: 储水池、泵浦机、电制冷设备（内部嵌入带动画的组件）。
- **核心中间层 (Graph Canvas)**: 基于 AntV X6 实例，支持无限拖拽平移、缩放、网格、暗色星空背景。
- **右侧参数层 (Property Panel)**: 提供类似截图中的“外观”、“状态”、“数据”、“动画”的多级手风琴面板配置。

## 2. 核心图元实现策略 (Core Entities)

我们将依托 X6 的系统重塑所有图元：

### 2.1 基础图形与文本 (Base Shapes)
直接继承 X6 的 `Node` 与 [Shape](file:///e:/bx-gitee/vue-fabric-editor/src/composables/useDragDrop.ts#35-202)。
- 通过修改 SVG attrs，实现圆角、阴影、渐变（立体感）。
- 支持双击直接就地编辑内部文本。

### 2.2 工业流体管道 (Fluid Pipes)
**不再使用孤立对象，而是改用拓扑图中的 “边 (Edge)” 或特定的路由路径。**
- **流体动画**: 利用 SVG 的 `stroke-dasharray` 和 `stroke-dashoffset` 加上 CSS `@keyframes`，实现丝滑的水流动画，不再需要手动在 JS 中写 RequestAnimationFrame 污染性能。
- **双向与流速**: 动态修改 Edge 的 `stroke` 颜色及动画速率即可实现。
- **拐弯管线**: 利用 X6 自带的 **Orthogonal Router (正交路由)**，拖拉拽自动生成规整的 90 度工业管道排布。

### 2.3 动态高级设备 (风扇 / 发电机等)
**采用 `@antv/x6-vue-shape` 技术。**
这是一个革命性的突破：我们编写一个普通的 Vue 组件 `<CoolingFan />`。
```vue
<template>
  <div class="device-box stereoscopic-3d shadow-xl">
     <div class="fan-blade animate-spin"></div> <!-- CSS 实现无限旋转 -->
     <p class="status-lcd">84.00 ℃</p>
  </div>
</template>
```
然后让 X6 直接将这个 Vue 组件当做一个“图元”嵌在画布中，完美支持任意复杂度的立体化 UI 和工业仪表盘数据展示！
