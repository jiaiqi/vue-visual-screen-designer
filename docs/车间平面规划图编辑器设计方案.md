## 项目概述

### 项目背景

本项目旨在开发一个基于 Web 的**车间平面规划图可视化编辑器**，用于创建和编辑类似下图所示的车间布局规划图：

```
┌─────────────────────────────────────────────────────────────────┐
│                      车间平面规划图                               │
├──────────┬──────────────────────────────────────────────────────┤
│ 碎料区   │  1 号机  2 号机  3 号机  4 号机  5 号机  6 号机  7 号机  │
├──────────┤                                                      │
│ 塑料粒子 │                                                      │
│ 放置区   │                                                      │
├──────────┤───────────────────────────┬──────────────────────────┤
│ 半成品   │                           │      模具     模具       │
│ 暂放区   │         通  道             │      放置区   维修区     │
├──────────┤                           │                          │
│ 半成品   │                           │                          │
│ 装配区   ├───────────────────────────┴──────────────────────────┤
│          │  大门  披峰   13 号  12 号  11 号  10 号  9 号   8 号   │
│          │        修理区  机    机    机    机    机    机       │
└──────────┴──────────────────────────────────────────────────────┘
```

### 核心需求

1. **可视化编辑** - 拖拽式操作，所见即所得
2. **基础图形** - 矩形 (机器/区域)、路径 (通道)、文字标签
3. **智能辅助** - 网格吸附、对齐线、标尺
4. **图层管理** - 对象层级调整、显示/隐藏、锁定
5. **撤销重做** - 完整的操作历史记录
6. **导入导出** - JSON 工程文件、PNG/SVG 图片导出

### 技术选型理由

#### 为什么选择 Fabric.js？

1. **成熟的 Canvas 抽象层** - 提供面向对象的图形模型
2. **丰富的交互支持** - 内置拖拽、缩放、旋转、选择
3. **强大的事件系统** - 完善的鼠标/触摸事件处理
4. **SVG 解析能力** - 支持导入 SVG 图形
5. **序列化支持** - 轻松保存/加载 JSON 数据
6. **活跃社区** - 大量示例和插件

#### 为什么选择 Vue 3 Composition API？

1. **逻辑复用** - Composables 模式便于代码组织
2. **类型友好** - 更好的 TypeScript 支持
3. **性能优化** - 更小的包体积和更好的运行时性能
4. **可测试性** - 逻辑与视图分离

#### 为什么选择 shadcn-vue？

1. **现代化设计** - 基于 Tailwind CSS 的美观设计
2. **高度可定制** - 代码直接复制到项目中，完全可控
3. **TypeScript 友好** - 完整的类型支持
4. **按需使用** - 只安装需要的组件，无冗余
5. **无障碍支持** - 基于 Radix Vue，内置 A11y 特性
6. **与 Vue 3 深度集成** - 完美支持 Composition API

#### 为什么选择 Lucide + Iconify？

1. **Lucide Icons** - 精致、一致的图标设计，完美适配现代 UI
2. **Iconify** - 20 万 + 图标资源，涵盖所有主流图标集
3. **unplugin-icons** - 自动按需加载，零运行时开销
4. **TypeScript 支持** - 完整的类型提示
5. **Tree-shaking** - 只打包使用的图标
6. **统一 API** - 所有图标集使用相同的调用方式

```vue
<script setup lang="ts">
import { computed } from 'vue'

const props = defineProps<{
  orientation: 'horizontal' | 'vertical'
  scrollOffset: number
  zoom: number
}>()

// 生成刻度
function generateTicks() {
  const ticks: number[] = []
  const step = 50 / props.zoom
  
  for (let i = 0; i < 10000; i += step) {
    ticks.push(i)
  }
  
  return ticks
}

// 绘制标尺
function drawRuler(ctx: CanvasRenderingContext2D) {
  const ticks = generateTicks()
  
  ticks.forEach(tick => {
    const isMajor = tick % (step * 10) === 0
    
    // 绘制刻度线
    ctx.beginPath()
    ctx.moveTo(tick, 0)
    ctx.lineTo(tick, isMajor ? 15 : 8)
    ctx.stroke()
    
    // 绘制数字
    if (isMajor && props.showNumbers) {
      ctx.fillText(formatValue(tick), tick + 2, 25)
    }
  })
}
</script>
```

### 6. 对齐线系统 (AlignGuides.vue)

#### 对齐检测算法

```typescript
interface Alignment {
  type: 'left' | 'right' | 'center' | 'top' | 'bottom' | 'middle'
  position: number
  guide: {
    x?: number
    y?: number
    length: number
  }
}

function detectAlignments(
  movingObject: fabric.Object,
  otherObjects: fabric.Object[],
  threshold: number = 5
): Alignment[] {
  const alignments: Alignment[] = []
  const movingBounds = movingObject.getBoundingRect()
  
  otherObjects.forEach(obj => {
    if (obj === movingObject) return
    
    const bounds = obj.getBoundingRect()
    
    // 检测左对齐
    if (Math.abs(movingBounds.left - bounds.left) < threshold) {
      alignments.push({
        type: 'left',
        position: movingBounds.left,
        guide: {
          x: movingBounds.left,
          length: Math.max(movingBounds.height, bounds.height)
        }
      })
    }
    
    // 检测右对齐
    if (Math.abs(movingBounds.right - bounds.right) < threshold) {
      alignments.push({
        type: 'right',
        position: movingBounds.right,
        guide: { x: movingBounds.right }
      })
    }
    
    // 检测水平居中对齐
    const movingCenterX = movingBounds.left + movingBounds.width / 2
    const boundsCenterX = bounds.left + bounds.width / 2
    if (Math.abs(movingCenterX - boundsCenterX) < threshold) {
      alignments.push({
        type: 'center',
        position: movingCenterX,
        guide: { x: movingCenterX }
      })
    }
    
    // 检测顶部对齐
    if (Math.abs(movingBounds.top - bounds.top) < threshold) {
      alignments.push({
        type: 'top',
        position: movingBounds.top,
        guide: { y: movingBounds.top }
      })
    }
    
    // 检测底部对齐
    if (Math.abs(movingBounds.bottom - bounds.bottom) < threshold) {
      alignments.push({
        type: 'bottom',
        position: movingBounds.bottom,
        guide: { y: movingBounds.bottom }
      })
    }
    
    // 检测垂直居中对齐
    const movingCenterY = movingBounds.top + movingBounds.height / 2
    const boundsCenterY = bounds.top + bounds.height / 2
    if (Math.abs(movingCenterY - boundsCenterY) < threshold) {
      alignments.push({
        type: 'middle',
        position: movingCenterY,
        guide: { y: movingCenterY }
      })
    }
  })
  
  return alignments
}
```

### 7. 历史记录系统 (History Store)

#### 命令模式实现

```typescript
// types/editor.ts
export interface Command {
  name: string
  execute(): void
  undo(): void
  redo(): void
}

// stores/history.ts
import { defineStore } from 'pinia'

interface HistoryState {
  undoStack: Command[]
  redoStack: Command[]
  maxSize: number
  isExecuting: boolean
}

export const useHistoryStore = defineStore('history', {
  state: (): HistoryState => ({
    undoStack: [],
    redoStack: [],
    maxSize: 50,
    isExecuting: false
  }),
  
  getters: {
    canUndo: (state) => state.undoStack.length > 0,
    canRedo: (state) => state.redoStack.length > 0
  },
  
  actions: {
    execute(command: Command) {
      if (this.isExecuting) return
      
      this.isExecuting = true
      
      try {
        command.execute()
        this.undoStack.push(command)
        this.redoStack = []
        
        // 限制历史记录大小
        if (this.undoStack.length > this.maxSize) {
          this.undoStack.shift()
        }
      } finally {
        this.isExecuting = false
      }
    },
    
    undo() {
      if (!this.canUndo) return
      
      const command = this.undoStack.pop()!
      this.isExecuting = true
      command.undo()
      this.isExecuting = false
      this.redoStack.push(command)
    },
    
    redo() {
      if (!this.canRedo) return
      
      const command = this.redoStack.pop()!
      this.isExecuting = true
      command.redo()
      this.isExecuting = false
      this.undoStack.push(command)
    },
    
    clear() {
      this.undoStack = []
      this.redoStack = []
    }
  }
})
```

```typescript
import { fabric } from 'fabric'

export function useGridSnap(canvas: fabric.Canvas, gridSize: number) {
  
  function snapToGrid(value: number): number {
    return Math.round(value / gridSize) * gridSize
  }
  
  function snapObjectToGrid(object: fabric.Object) {
    const snappedX = snapToGrid(object.left || 0)
    const snappedY = snapToGrid(object.top || 0)
    
    object.set({
      left: snappedX,
      top: snappedY
    })
  }
  
  function setupGridSnapping() {
    canvas.on('object:moving', (e) => {
      const object = e.target
      if (!object) return
      
      // 按住 Shift 键临时禁用吸附
      if (e.e.shiftKey) return
      
      object.set({
        left: snapToGrid(object.left || 0),
        top: snapToGrid(object.top || 0)
      })
    })
    
    canvas.on('object:scaling', (e) => {
      const object = e.target
      if (!object) return
      
      if (e.e.shiftKey) return
      
      object.set({
        width: snapToGrid(object.getScaledWidth()),
        height: snapToGrid(object.getScaledHeight())
      })
    })
  }
  
  return {
    snapToGrid,
    snapObjectToGrid,
    setupGridSnapping
  }
}
```

### 2. 智能对齐线检测

```typescript
// composables/useSnaplines.ts
import { fabric } from 'fabric'

interface GuideLine {
  x1: number
  y1: number
  x2: number
  y2: number
  color: string
  lineWidth: number
}

export function useSnaplines(canvas: fabric.Canvas) {
  const threshold = 5 // 吸附阈值 (像素)
  const guides: fabric.Line[] = []
  
  function getBounds(obj: fabric.Object) {
    const rect = obj.getBoundingRect()
    return {
      left: rect.left,
      right: rect.left + rect.width,
      top: rect.top,
      bottom: rect.top + rect.height,
      centerX: rect.left + rect.width / 2,
      centerY: rect.top + rect.height / 2
    }
  }
  
  function detectAlignments(moving: fabric.Object) {
    const movingBounds = getBounds(moving)
    const alignments: { type: string; position: number; guide: GuideLine }[] = []
    
    canvas.getObjects().forEach(obj => {
      if (obj === moving || obj.type === 'guide') return
      
      const bounds = getBounds(obj)
      
      // 检测水平对齐
      checkHorizontalAlign(movingBounds, bounds, alignments)
      
      // 检测垂直对齐
      checkVerticalAlign(movingBounds, bounds, alignments)
    })
    
    return alignments
  }
  
  function checkHorizontalAlign(
    moving: ReturnType<typeof getBounds>,
    other: ReturnType<typeof getBounds>,
    alignments: any[]
  ) {
    // 左对齐
    if (Math.abs(moving.left - other.left) < threshold) {
      alignments.push({
        type: 'left',
        position: moving.left,
        guide: {
          x1: moving.left,
          y1: Math.min(moving.top, other.top),
          x2: moving.left,
          y2: Math.max(moving.bottom, other.bottom),
          color: '#00ff00',
          lineWidth: 1
        }
      })
      // 执行吸附
      moving.left = other.left
    }
    
    // 右对齐
    if (Math.abs(moving.right - other.right) < threshold) {
      alignments.push({
        type: 'right',
        position: moving.right,
        guide: {
          x1: moving.right,
          y1: Math.min(moving.top, other.top),
          x2: moving.right,
          y2: Math.max(moving.bottom, other.bottom),
          color: '#00ff00',
          lineWidth: 1
        }
      })
      moving.left = other.right - (moving.right - moving.left)
    }
    
    // 水平居中对齐
    if (Math.abs(moving.centerX - other.centerX) < threshold) {
      alignments.push({
        type: 'center',
        position: moving.centerX,
        guide: {
          x1: moving.centerX,
          y1: Math.min(moving.top, other.top),
          x2: moving.centerX,
          y2: Math.max(moving.bottom, other.bottom),
          color: '#00ff00',
          lineWidth: 1
        }
      })
      moving.left = other.centerX - (moving.right - moving.left) / 2
    }
  }
  
  function checkVerticalAlign(
    moving: ReturnType<typeof getBounds>,
    other: ReturnType<typeof getBounds>,
    alignments: any[]
  ) {
    // 顶部对齐
    if (Math.abs(moving.top - other.top) < threshold) {
      alignments.push({
        type: 'top',
        position: moving.top,
        guide: {
          x1: Math.min(moving.left, other.left),
          y1: moving.top,
          x2: Math.max(moving.right, other.right),
          y2: moving.top,
          color: '#00ff00',
          lineWidth: 1
        }
      })
      moving.top = other.top
    }
    
    // 底部对齐
    if (Math.abs(moving.bottom - other.bottom) < threshold) {
      alignments.push({
        type: 'bottom',
        position: moving.bottom,
        guide: {
          x1: Math.min(moving.left, other.left),
          y1: moving.bottom,
          x2: Math.max(moving.right, other.right),
          y2: moving.bottom,
          color: '#00ff00',
          lineWidth: 1
        }
      })
      moving.top = other.bottom - (moving.bottom - moving.top)
    }
    
    // 垂直居中对齐
    if (Math.abs(moving.centerY - other.centerY) < threshold) {
      alignments.push({
        type: 'middle',
        position: moving.centerY,
        guide: {
          x1: Math.min(moving.left, other.left),
          y1: moving.centerY,
          x2: Math.max(moving.right, other.right),
          y2: moving.centerY,
          color: '#00ff00',
          lineWidth: 1
        }
      })
      moving.top = other.centerY - (moving.bottom - moving.top) / 2
    }
  }
  
  function showGuides(alignments: any[]) {
    // 清除旧的对齐线
    clearGuides()
    
    // 创建新的对齐线
    alignments.forEach(align => {
      const line = new fabric.Line([
        align.guide.x1,
        align.guide.y1,
        align.guide.x2,
        align.guide.y2
      ], {
        stroke: align.guide.color,
        strokeWidth: align.guide.lineWidth,
        selectable: false,
        evented: false,
        opacity: 0.8
      })
      
      guides.push(line)
      canvas.add(line)
    })
  }
  
  function clearGuides() {
    guides.forEach(guide => canvas.remove(guide))
    guides.length = 0
  }
  
  function setupSnaplines() {
    canvas.on('object:moving', (e) => {
      if (!e.target || e.e.shiftKey) return
      
      const alignments = detectAlignments(e.target)
      showGuides(alignments)
    })
    
    canvas.on('object:moved', () => {
      clearGuides()
    })
  }
  
  return {
    setupSnaplines,
    clearGuides
  }
}
```

```typescript
// composables/useDragDrop.ts
import { fabric } from 'fabric'
import { WorkshopObjectType } from '@/types/editor'

export function useDragDrop(canvas: fabric.Canvas) {
  
  function handleDragOver(e: DragEvent) {
    e.preventDefault()
    e.dataTransfer!.dropEffect = 'copy'
  }
  
  function handleDrop(e: DragEvent) {
    e.preventDefault()
    
    const type = e.dataTransfer?.getData('application/x-shape-type')
    if (!type) return
    
    const rect = canvas.getElement().getBoundingClientRect()
    const x = e.clientX - rect.left
    const y = e.clientY - rect.top
    
    // 考虑画布缩放和平移
    const pointer = canvas.getPointer(e)
    
    createShape(type as WorkshopObjectType, { x: pointer.x, y: pointer.y })
  }
  
  function createShape(type: WorkshopObjectType, position: { x: number; y: number }) {
    let shape: fabric.Object
    
    switch (type) {
      case WorkshopObjectType.MACHINE:
        shape = new fabric.Rect({
          left: position.x,
          top: position.y,
          width: 100,
          height: 80,
          fill: '#ffb6c1',
          stroke: '#333',
          strokeWidth: 1
        })
        break
        
      case WorkshopObjectType.AREA:
        shape = new fabric.Rect({
          left: position.x,
          top: position.y,
          width: 200,
          height: 150,
          fill: '#98fb98',
          stroke: '#333',
          strokeWidth: 1,
          opacity: 0.8
        })
        break
        
      case WorkshopObjectType.PATH:
        shape = new fabric.Rect({
          left: position.x,
          top: position.y,
          width: 300,
          height: 40,
          fill: '#ffff00',
          stroke: '#333',
          strokeWidth: 1
        })
        break
        
      default:
        shape = new fabric.Rect({
          left: position.x,
          top: position.y,
          width: 100,
          height: 100,
          fill: '#ddd'
        })
    }
    
    canvas.add(shape)
    canvas.setActiveObject(shape)
    
    // 触发对象创建事件
    canvas.fire('object:created', { target: shape })
  }
  
  function setupDragDrop() {
    const canvasElement = canvas.getElement()
    canvasElement.addEventListener('dragover', handleDragOver)
    canvasElement.addEventListener('drop', handleDrop)
  }
  
  return {
    setupDragDrop,
    createShape
  }
}
```

### 4. 快捷键系统

```typescript
// composables/useShortcuts.ts
import { onMounted, onUnmounted } from 'vue'
import { useEditorStore } from '@/stores/editor'
import { useHistoryStore } from '@/stores/history'

export function useShortcuts() {
  const editorStore = useEditorStore()
  const historyStore = useHistoryStore()
  
  const shortcuts: Record<string, (e: KeyboardEvent) => void> = {
    // 撤销 Ctrl+Z
    'ctrl+z': (e) => {
      e.preventDefault()
      historyStore.undo()
    },
    
    // 重做 Ctrl+Y
    'ctrl+y': (e) => {
      e.preventDefault()
      historyStore.redo()
    },
    
    // 删除 Delete / Backspace
    'delete': (e) => {
      e.preventDefault()
      editorStore.deleteSelected()
    },
    
    // 全选 Ctrl+A
    'ctrl+a': (e) => {
      e.preventDefault()
      editorStore.selectAll()
    },
    
    // 复制 Ctrl+C
    'ctrl+c': (e) => {
      e.preventDefault()
      editorStore.copy()
    },
    
    // 粘贴 Ctrl+V
    'ctrl+v': (e) => {
      e.preventDefault()
      editorStore.paste()
    },
    
    // 多选 Shift+ 点击
    'shift': (e) => {
      editorStore.enableMultiSelect(true)
    }
  }
  
  function handleKeyDown(e: KeyboardEvent) {
    const key = e.key.toLowerCase()
    const modifiers = []
    
    if (e.ctrlKey) modifiers.push('ctrl')
    if (e.shiftKey) modifiers.push('shift')
    if (e.altKey) modifiers.push('alt')
    
    const shortcutKey = [...modifiers, key].join('+')
    
    if (shortcuts[shortcutKey]) {
      shortcuts[shortcutKey](e)
    }
  }
  
  function handleKeyUp(e: KeyboardEvent) {
    if (e.key === 'Shift') {
      editorStore.enableMultiSelect(false)
    }
  }
  
  onMounted(() => {
    window.addEventListener('keydown', handleKeyDown)
    window.addEventListener('keyup', handleKeyUp)
  })
  
  onUnmounted(() => {
    window.removeEventListener('keydown', handleKeyDown)
    window.removeEventListener('keyup', handleKeyUp)
  })
}
```

```typescript
import { computed } from 'vue'

const buttonVariants = cva(
  'inline-flex items-center justify-center whitespace-nowrap rounded-md text-sm font-medium ring-offset-background transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50',

        outline:
          'border border-input bg-background hover:bg-accent hover:text-accent-foreground',
        secondary:
          'bg-secondary text-secondary-foreground hover:bg-secondary/80',
        ghost: 'hover:bg-accent hover:text-accent-foreground',
        link: 'text-primary underline-offset-4 hover:underline',
      },
      size: {
        default: 'h-10 px-4 py-2',
        sm: 'h-9 rounded-md px-3',
        lg: 'h-11 rounded-md px-8',
        icon: 'h-10 w-10',
      },
    },
    defaultVariants: {
      variant: 'default',
      size: 'default',
    },
  }
)

type ButtonVariants = VariantProps<typeof buttonVariants>

interface Props {
  variant?: ButtonVariants['variant']
  size?: ButtonVariants['size']
  disabled?: boolean
}

const props = defineProps<Props>()

const classes = computed(() => cn(buttonVariants({ variant: props.variant, size: props.size })))
</script>
```
